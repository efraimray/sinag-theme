    About this project
    
      
    The problem. Most small businesses in Bukidnon and across Mindanao run their online presence from a Facebook page. When they do get a website, it is often a heavy page-builder theme that loads slowly on mobile data, and the phone number is typed into a dozen places that all go stale the day the number changes.
    
      
    The fix. Sinag is a block theme built on theme.json with ready-made sections for cafés, stores, clinics and cooperatives. A small Business Details screen stores the phone, hours, address and chat link once, and the WordPress Block Bindings API prints them into the header, footer, hero buttons and contact card.
    
      
    Who it is for

    Features
    
      
      
        
    • Five style variations: Sinag, Kape, Dagat, Palay and Gabi (dark)
      • 
        
    • Patterns: hero, services, peso price list, hours and location, FAQ, message band
      • 
        
    • Business Details bound into blocks, with automatic +63 Call links
      • 
        
    • System font stacks, zero theme JavaScript, zero external requests
      • 
        
    • Every palette passes WCAG AA, body text passes AAA
