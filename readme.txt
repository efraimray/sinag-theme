A fast, script-free block theme for Philippine small businesses, with five style variations and a Business Details screen that fills every pattern.

== Description ==

Sinag (Filipino for "ray of light") is a lightweight block theme for cafés, sari-sari stores, clinics, cooperatives, review centers and service shops.

* Five style variations: Sinag, Kape, Dagat, Palay and Gabi (dark).
* Ready-made patterns: sunrise hero, services grid, price list in pesos, hours and location, FAQ and a message call-to-action.
* Appearance → Business Details: type your phone, email, address, hours and Messenger link once. The header, footer and patterns pick them up through the WordPress Block Bindings API.
* Call buttons convert local numbers such as 0917 123 4567 to +63 links automatically.
* No theme JavaScript, no web fonts and no external requests. Every palette passes WCAG AA; body text passes AAA.

== Installation ==

1. In wp-admin go to Appearance → Themes → Add New → Upload Theme.
2. Choose sinag-theme.zip, click Install Now, then Activate.
3. Go to Appearance → Business Details and fill in your details.
4. Open Appearance → Editor → Styles to pick a style variation.

== Frequently Asked Questions ==

= The editor shows sample text instead of my phone number. Is that wrong? =

No. In version 1.0.0 the bound values are filled in when the page is rendered on the front end. The editor keeps showing the pattern's sample text.

= Does it need any plugin? =

No. Sinag works on a plain WordPress 6.6 or newer install.

= Can I use it for client work? =

Yes. It is GPL-licensed. Install it, customise it and charge for your setup and care services.
